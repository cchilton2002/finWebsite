# Wiseheart

React + TypeScript + Tailwind v4 (Vite).

    npm install
    npm run dev

- Copy lives in `src/content.ts` (email, people, testimonials).
- Drop photos in `public/images/richard.jpg` and `public/images/fin.jpg`. Initials show until they exist.
- Colours and fonts are set in `src/index.css`.
